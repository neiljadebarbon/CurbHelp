# CurbHelp

CurbHelp is a lightweight prototype for an exterior-only neighborhood microtask marketplace.

## Prototype behavior

- No login required.
- Designed as an iPhone-style mobile app even when opened on desktop.
- Requester can post a simple exterior task.
- Helper can preview the route and accept the task.
- Completion screen shows GPS check-in and before/after proof.
- Demo state is stored only in the browser with `localStorage`.
- No real payments, GPS, identity verification, or backend are connected.

## Screens

1. Home
2. Post a Task
3. Helper View
4. Complete Task
5. Tasks
6. Route
7. Profile

## Run locally

Open `index.html` in a browser.

## GitHub Pages

This repository includes a Pages workflow. In GitHub, open:

**Settings → Pages → Build and deployment → Source → GitHub Actions**

After Pages is enabled, pushes to `main` will deploy the prototype.

## Academic prototype

This version is intentionally simple and is designed for product-design demonstration and user feedback, not production use.
